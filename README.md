# 스톱워치

브라우저에서 바로 쓰는 스톱워치 웹페이지입니다. `index.html` 하나로 동작합니다.

## 기능
- 1/100초 표시, 육상 기록 표기 (`58.21`, `4:05.32`, `1:02:03.45`)
- 랩 타임 · 직전 대비(±) · 스플릿(누적) · 평균 랩, 가장 빠른/느린 랩 표시
- 측정 중 / 일시정지 / 대기 상태 표시
- 하단 고정 큰 버튼: 측정 중에는 큰 **랩** 버튼, 멈추면 **초기화**(길게 누르기)
- 손가락이 닿는 순간 기록, 0.3초 안의 중복 랩 무시
- 새로고침해도 기록 유지, 측정 중 화면 꺼짐 방지, 랩 진동(지원 기기)
- 단축키: `Space` 시작·정지, `L` 랩, `R` 초기화
- 기록 복사(표 형식), 다크 모드 자동 전환
- 입체파 화풍의 얼굴 그림 배경

## 사용법
`index.html`을 브라우저로 열면 됩니다.
